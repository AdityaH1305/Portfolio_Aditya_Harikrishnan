# Aditya Harikrishnan — Portfolio

A modern, interactive developer portfolio built with Next.js, showcasing projects across machine learning, full-stack development, computer vision, and systems engineering.

**Live Site:** [adityaharikrishnan.vercel.app](https://adityaharikrishnan.vercel.app)

---

## Overview

This portfolio is an interactive exploration of my work, technical interests, and ongoing projects. It combines structured content with generative visuals, interactive experiences, and performance-conscious animations to create a portfolio that goes beyond a conventional project showcase.

---

## Features

- Generative canvas-based system atlas that evolves as you navigate through the portfolio
- Interactive project showcases with expandable previews
- Walkthrough videos loaded progressively as they enter the viewport
- Command palette with `Ctrl` / `Cmd` + `K` navigation
- Hidden interactive easter egg
- Responsive layouts across desktop and mobile
- `prefers-reduced-motion` support throughout the experience
- Lazy loading for visual and media assets

## Selected Projects

### Ludex

A hybrid recommendation engine for Steam games combining content-based and collaborative filtering approaches.

- **+27% Precision@20** over the content-based baseline
- **+13% Precision@20** over collaborative filtering alone
- Trained and evaluated across **57,000+ titles and 1,200+ players**
- Combines TF-IDF-based content representations with collaborative filtering
- Full technical report available through the portfolio

### Gait Recognition via Multi-Modal Fusion

A multi-modal gait recognition system exploring the fusion of complementary gait representations for person identification.

- **98% Rank-1 accuracy** under normal walking conditions
- Explores multi-modal feature fusion for gait-based recognition
- Combines complementary visual representations to improve recognition performance

### Modified Double U-Net

A modified semantic segmentation architecture based on the Double U-Net framework, developed for medical image segmentation.

- **95.94% mean IoU**
- **1.58 percentage point improvement** over the baseline
- Explores architectural modifications to improve segmentation performance
- Evaluated on medical ultrasound imagery
